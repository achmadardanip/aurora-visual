# Data, lisensi dan anotasi

Sumber primer diperiksa pada 12 September 2026. Salinan README yang dibaca dan hasil pemeriksaan lisensi tersedia di `artifacts/reports/*-source.txt` dan `source-verification.json`. Tidak ada dataset besar/bobot berlisensi yang diunduh otomatis.

**MAFINDO V1 bukan dataset training visual AURORA.** Uji live hanya mengembalikan metadata fact-check yang dinormalisasi (ID, judul, klasifikasi/status, tanggal), tanpa pasangan byte gambar–caption, region gold, label atom S/C/U, atau grant lisensi training/redistribusi yang telah diverifikasi. Karena itu respons API tidak diimpor sebagai corpus penelitian dan tidak dikirim ke GPU. Penggunaan data untuk training baru boleh dilakukan setelah pemilik data memberikan ketentuan lisensi tertulis, media diperoleh secara sah, dan anotasi visual sesuai kontrak tersedia.

|---|---|---|

GitHub tidak menyajikan LICENSE pada endpoint lisensi yang diperiksa; hak VisualNews/media harus diperiksa sebelum penggunaan/redistribusi. |

Importer CLI menyediakan adapter format di atas untuk berkas lokal yang diperoleh secara sah. Pengguna memberikan image-root, split, license-note, serta groups.json; tidak ada download URL input. Pada COSMOS caption diperluas menjadi baris terpisah, pair_context_label disimpan sebagai metadata dan post_label null. Proposal box sumber tidak diangkat menjadi gold grounding.

```sh
uv run aurora import-dataset --source verite --input /data/VERITE.csv \
  --image-root /data/VERITE --groups /data/groups.json --split test \
  --license-note 'Research access approved; original media rights retained' \
  --output data/manifests/verite.jsonl
```

`groups.json` memetakan indeks baris rilis asli ke `{event_id,source_group,parent_id,source_url}`. Untuk NewsCLIPpings tambahkan `--visualnews /data/visualnews/origin/data.json`. Semua variasi satu gambar/peristiwa/sumber/parent harus satu split; hashes gambar identik tidak boleh melintas split. Diperlukan peninjauan event/source oleh manusia, karena hash piksel tidak menemukan near-duplicate atau sindikasi otomatis.

## Manifest internal

JSONL divalidasi `Example` di `training/data.py`. Field wajib: sample_id, image (relatif manifest), image_sha256, caption persis, language, dataset, split, event_id, source_group, parent_id, license, source_url, post_label, annotations, data_kind dan extensions (default {}). `annotations` berisi `{atom: Atom lengkap, label: S/C/U atau null, regions: normalized bbox[], provenance: human/weak/fixture/unreviewed, quality: skor terukur atau null}`. `data_kind` research/fixture wajib eksplisit. Unreviewed tidak boleh memasok gold label. Training menolak atom tanpa label; cache-features tetap dapat memproses data tanpa anotasi.

`extensions.hard_positive_id` menunjuk sample dengan image dan split sama; `atom_correspondence` adalah array pemetaan indeks atom asal ke indeks atom pasangan, bijektif dan dengan gold label sama. Grid kolomnya identik karena gambar/config sama. Generator weak supervision mengeluarkan role/entity/attribute/relation swap, number change, negation serta synonym/voice/paraphrase. Ukuran edit dan kelulusan aturan grammar dicatat; confidence empiris null. Perubahan tanpa observasi alternatif tidak menjadi C. Label hard positive hanya diwariskan jika label sumber diberikan; perubahan makna kecil tidak membuktikan observabilitas.

## Benchmark atomisasi manusia

`data/benchmarks/pilot-candidates.jsonl` terpisah dari fixture unit test. Isinya kandidat caption ID/EN dengan kondisi negasi, peran, angka, tanggal, lokasi, sebab, koreferensi, Unicode dan voice. `gold_atoms` serta identitas/review dua anotator masih null: **belum merupakan benchmark ditinjau manusia**. Kode tidak mengarang review manusia.

`data/benchmarks/mafindo-candidates.jsonl` dihasilkan oleh pipeline judge (dari corpus curation MAFINDO): 14 September 2026, 200 judul ber-kata kunci foto/video/gambar ditriage LLM lokal gratis; 34 klaim visual parseable lolos filter dan menjadi kandidat caption benchmark parser (prefix verdict [SALAH]/[KLARIFIKASI] dibuang; verdict asli tersimpan di provenance). File berstatus lokal (tidak dikomit karena tanpa lisensi redistribusi) dan dapat dibuat ulang: `make mafindo-corpus` lalu `aurora judge --task triage`. `gold_atoms` tetap null dan `evaluate-parser` melaporkan `awaiting_human_review` — kandidat, bukan gold.

Pilot 100 dan target 500–1.000 contoh merupakan rencana riset. Dua anotator menyusun atom minimal, spans, dependensi dan label/region independen; adjudikasi mencatat perbedaan dan keputusan. Bekukan split berdasarkan event/image/source sebelum tuning. Jalankan evaluasi parser hanya setelah gold_atoms dan review tersedia. Jangan gunakan contoh UI/fixture pada evaluasi confirmatory.

## Model pretrained per kapabilitas (kecuali head S/C/U)

Satu-satunya komponen yang dilatih proyek ini adalah **head tiga keadaan S/C/U** (bagian berikutnya), dan ia sengaja **tidak** ada di registri pretrained. Unduhan bersifat eksplisit (`aurora models --download …`), masuk ke `{AURORA_DATA_DIR}/models`, dan dicatat dalam manifest berisi model id, lisensi, dan sha256 tiap berkas — tidak ada unduhan otomatis saat analisis.

## Corpus curation MAFINDO

`aurora mafindo-corpus --limit N --output data/mafindo/corpus.jsonl` menarik arsip MAFINDO via API V2 (`POST /api/antihoax/` limit/offset, `get_total`) dengan deduplikasi ID, resume state, rate limiting, dan redaksi API key. Hasil adalah **corpus curation**: kandidat caption untuk benchmark parser dan sumber teks weak-supervision — bukan dataset visual. Record memuat judul/konten/fakta/klasifikasi/tanggal dan URL media sebagai referensi metadata; media tidak diunduh. Total arsip per 14 September 2026: **36.129 record** (permintaan 100.000 data tidak dapat dipenuhi karena basis data penyedia berisi 36.129). Penggunaan untuk training visual tetap menunggu grant lisensi tertulis pemilik data, media yang diperoleh sah, dan anotasi visual sesuai kontrak.

`aurora judge --task triage --input data/mafindo/corpus.jsonl --limit N` menjalankan LLM gratis lokal (Ollama, `AURORA_LLM_URL`/`AURORA_LLM_MODEL`) untuk triage kandidat caption: klaim visual vs non-visual dan jenis klaim (action/location/time/identity/quantity/…). `aurora judge --task weak-pairs --caption "…"` menguji pasangan weak-supervision: parafrasa harus mempertahankan makna, perturbasi harus mengubah klaim; pasangan yang tidak konsisten ditolak dan tidak masuk training. Verdict judge berprovenance `llm-judge-v1`, tidak pernah gold, dan judge teks tidak dapat menilai S/C/U visual karena tidak melihat gambar.

Ketentuan pemakaian mengikuti bagian Manifest internal: split per event/image/source, dua anotator untuk gold, provenance/`groups.json` eksplisit, dan tidak ada angka evaluasi sebelum data benar-benar dianotasi.

## Provenance dan screening asal media

Setiap upload dapat menghasilkan `extensions.aurora_visual.screening` pada run analysis. Screening membaca byte asli dan hanya mempertahankan nama field metadata/presence indicator, bukan nilai EXIF mentah yang mungkin sensitif. Marker perangkat lunak generatif yang dikenal dapat menghasilkan `likely_ai_generated`; metadata kamera tanpa marker kuat dapat menghasilkan `no_strong_ai_signal`; sisanya `inconclusive`. Semua label ini terbatas pada pemeriksaan lokal dan selalu disertai batas bahwa mereka tidak memengaruhi S/C/U maupun kebenaran caption.

Manifest C2PA kini diurai dan tanda tangannya divalidasi dengan [c2pa-python](https://github.com/contentauth/c2pa-python) terhadap trust store bawaan SDK; trust anchor tambahan dapat ditambah admin via `AURORA_C2PA_TRUST_ANCHORS` (path file PEM atau PEM inline). Hanya manifest tervalidasi dengan `digitalSourceType` algoritmik terlatih (trainedAlgorithmicMedia/compositeWithTrainedAlgorithmicMedia) yang menaikkan label `likely_ai_generated`; manifest yang tidak lolos validasi dilaporkan `present_unverified` dan klaim provenance di dalamnya tidak dipercaya. Validasi ini bukan audit rantai kepercayaan penuh, tidak memeriksa tanda waktu/kebijakan signer, dan manifest valid sekalipun tidak membuktikan kebenaran caption.

Deteksi watermark tak terlihat SynthID tersedia sebagai adapter gateway operator (`aurora_visual.synthid`, provider `synthid-detector`). SynthID Detector resmi masih portal early-access tanpa API publik terdokumentasi, sehingga endpoint adalah gateway yang dikonfigurasi admin (`AURORA_SYNTHID_ENDPOINT` + API key, wajib keduanya saat `AURORA_SYNTHID_ENABLED=true`) dan setiap analisis tetap memilih opt-in `extensions.aurora_visual.options.synthid_detector` pada mode live; adapter hanya diverifikasi dengan mock HTTP. Verdikt positif (`synthid_watermark_detected`) adalah indikasi konten Google AI; verdikt negatif tidak membuktikan gambar kamera karena tidak semua generator memakai SynthID. Deteksi AI-image/deepfake Hive V3 tetap jalur provider terpisah (opt-in per analisis). Metadata dapat dihapus atau dimodifikasi; ketiadaan sinyal tidak membuktikan gambar berasal dari kamera.


[OpenCLIP](https://github.com/mlfoundations/open_clip) diperiksa dari README primer; encoder pretrained harus dipilih beserta lisensi/model card datasetnya. Dukungan Indonesia tidak diasumsikan dari kemampuan tokenizer menerima teks. Segmentasi runtime memakai Mask R-CNN pretrained (registri `aurora models`); FG-CLIP dan TextRegion belum diaktifkan karena checkpoint/lisensi dan dependensi belum diverifikasi, sedangkan SAM 2.1 terunduh sebagai opsi lanjutan dengan adapter yang belum diaktifkan. [Tesseract tessdata](https://github.com/tesseract-ocr/tessdata) menjelaskan traineddata; engine lokal menyediakan ind dan eng dan telah diuji. OCR score adalah skor engine, bukan confidence faktual.
