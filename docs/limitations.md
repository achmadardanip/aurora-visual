# Batas yang perlu diketahui

- Screening asal media membaca nama/presence metadata secara lokal dan memakai c2pa-python untuk mengurai manifest C2PA serta memvalidasi tanda tangannya terhadap trust store bawaan SDK (plus trust anchor operator opsional). Validasi ini bukan audit rantai kepercayaan penuh, tidak memeriksa kebijakan signer/tanda waktu, dan manifest valid sekalipun tidak membuktikan kebenaran caption; manifest tidak tervalidasi tidak dipercaya. Saat provider Hive dipilih, deteksi AI-image/deepfake model V3 dijalankan pada byte asli: hasilnya sinyal probabilistik dengan ambang provider 0.9, `not_ai_generated` tidak dianggap bukti autentisitas. Screening tidak mengubah Supported/Contradicted/Unobservable atau verdict fakta.
- Tidak ada detektor AI-image, deepfake, atau watermark tak terlihat tervalidasi secara lokal yang dikonfigurasi pada jalur lokal murni. Deteksi Hive V3 adalah sinyal provider eksternal (opt-in, mode live), bukan validator yang dievaluasi independen di mesin ini. Deteksi watermark SynthID adalah adapter gateway operator: SynthID Detector resmi masih portal early-access tanpa API publik terdokumentasi, adapter hanya diverifikasi dengan mock HTTP, dan hasil negatif (tidak ada watermark) tidak membuktikan gambar berasal dari kamera karena tidak semua generator memakai SynthID. Status `unavailable` berarti tidak dinilai, bukan hasil negatif.
- MAFINDO V1 hanya bridge diagnostik baca-saja server-side. Hasil provider tidak tersimpan dalam bundle, retrieval, decision, atau assessment visual; klasifikasi/status provider tidak diterjemahkan sebagai label AURORA. Kunci hanya berada pada environment server dan output error tidak mengekspos URL/key.
- OpenCLIP adapter tersedia, beku, dan bobot `ViT-B-32-quickgelu/openai` telah diunduh serta diverifikasi inferensi pada mesin ini (MPS); embed bukan bukti kebenaran klaim. Bahasa Indonesia pada model OpenCLIP standar belum tervalidasi; parser Indonesia tidak bergantung pada model bahasa Inggris. Tag `openai` harus dipasangkan dengan varian `*-quickgelu` agar aktivasi cocok.
- Parser rule berbasis pola, bukan dependency/SRL/NER lengkap. Ambiguitas, pronomina, kalimat majemuk, kuantitas kompleks dan voice yang tidak dicakup dapat memerlukan koreksi. Parser_confidence selalu null sampai ada pengukuran yang sah. Structured LLM adapter memvalidasi schema/span/entity/negasi (span dijangkarkan ulang ke offset caption yang terukur) dan tetap membutuhkan audit manusia; kegagalan parser LLM akan fallback ke aturan lokal dengan peringatan.
- Grid bukan segmentasi objek. Relation cost adalah aproksimasi anchor dan geometri unary. Belum ada detektor relasi/atribut objek, counting dengan cakupan penuh, geolocation, identifikasi orang atau validasi tanggal pengambilan foto. Cue tidak tersedia tidak pernah otomatis menjadi kontradiksi.
- OCR ind+eng dijalankan secara nyata, tetapi engine dapat salah. OCR tidak membuktikan kebenaran tulisan atau waktu kejadian. Skor parser/region/alignment/observabilitas tidak terkalibrasi.
- Head dilatih/dimuat/resume pada fixture CPU untuk verifikasi engineering. Model penelitian, checkpoint valid untuk live, kalibrasi, kinerja umum, lima-seed confirmatory, lintas dataset dan GPU profiling belum dijalankan.
- Benchmark kandidat tersedia; belum ada dua anotator manusia atau gold benchmark ditinjau. Dataset besar tidak diperoleh otomatis. VERITE/COSMOS memiliki persyaratan akses; NewsCLIPpings membutuhkan pemeriksaan lisensi sumber, MMFakeBench memiliki protokol penggunaan. Tidak ada angka penelitian yang direkayasa.
- API local single-user memakai satu token per pemilik pada mode publik. Belum ada SSO, manajemen pengguna/tenant, registry izin granular, antrean terdistribusi, maupun deployment produksi yang diverifikasi. Docker dan TLS config disediakan tetapi belum dijalankan karena runtime Docker tidak tersedia.
- Ekspor JSON dapat memuat metadata tanpa media; ZIP memerlukan media dan seluruh sidecar yang direferensikan. History/audit berisi snapshot kasus lokal yang bisa sensitif; backup dan akses folder harus dilindungi pemilik mesin. Audit ringkas tidak mencatat API key.
- Kontrak diverifikasi di Pydantic, JSON Schema dan JCS lintas JavaScript/Python, termasuk contoh paket asli. Repo modul 2/3 tidak berada di workspace; pengujian validator independen di kedua repo itu tetap bagian serah terima tim.
