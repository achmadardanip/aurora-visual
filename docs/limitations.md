# Batas yang perlu diketahui

- Screening asal media hanya membaca nama/presence metadata dan marker byte C2PA/JUMBF. Ia bukan C2PA manifest/signature/trust-chain validator dan metadata dapat dihapus/diubah. Penanda software generatif adalah sinyal terbatas, bukan generalisasi bahwa media buatan AI; ketiadaan sinyal bukan bukti media kamera.
- Tidak ada detektor AI-image, deepfake, atau watermark tak terlihat tervalidasi yang dikonfigurasi. Status `unavailable` berarti tidak dinilai, bukan hasil negatif. Screening tidak mengubah Supported/Contradicted/Unobservable atau verdict fakta.
- MAFINDO V1 hanya bridge diagnostik baca-saja server-side. Hasil provider tidak tersimpan dalam bundle, retrieval, decision, atau assessment visual; klasifikasi/status provider tidak diterjemahkan sebagai label AURORA. Kunci hanya berada pada environment server dan output error tidak mengekspos URL/key.
- OpenCLIP adapter tersedia dan beku, tetapi unduhan/inferensi bobot pretrained belum diverifikasi pada mesin ini. Tidak ada random model yang disajikan sebagai trained. Bahasa Indonesia pada model OpenCLIP standar belum tervalidasi; parser Indonesia tidak bergantung pada model bahasa Inggris.
- Parser rule berbasis pola, bukan dependency/SRL/NER lengkap. Ambiguitas, pronomina, kalimat majemuk, kuantitas kompleks dan voice yang tidak dicakup dapat memerlukan koreksi. Parser_confidence selalu null sampai ada pengukuran yang sah. Structured LLM adapter memvalidasi schema/span/entity/negasi dan tetap membutuhkan audit manusia; live endpoint LLM belum diuji.
- Grid bukan segmentasi objek. Relation cost adalah aproksimasi anchor dan geometri unary. Belum ada detektor relasi/atribut objek, counting dengan cakupan penuh, geolocation, identifikasi orang atau validasi tanggal pengambilan foto. Cue tidak tersedia tidak pernah otomatis menjadi kontradiksi.
- OCR ind+eng dijalankan secara nyata, tetapi engine dapat salah. OCR tidak membuktikan kebenaran tulisan atau waktu kejadian. Skor parser/region/alignment/observabilitas tidak terkalibrasi.
- Head dilatih/dimuat/resume pada fixture CPU untuk verifikasi engineering. Model penelitian, checkpoint valid untuk live, kalibrasi, kinerja umum, lima-seed confirmatory, lintas dataset dan GPU profiling belum dijalankan.
- Benchmark kandidat tersedia; belum ada dua anotator manusia atau gold benchmark ditinjau. Dataset besar tidak diperoleh otomatis. VERITE/COSMOS memiliki persyaratan akses; NewsCLIPpings membutuhkan pemeriksaan lisensi sumber, MMFakeBench memiliki protokol penggunaan. Tidak ada angka penelitian yang direkayasa.
- API local single-user memakai satu token per pemilik pada mode publik. Belum ada SSO, manajemen pengguna/tenant, registry izin granular, antrean terdistribusi, maupun deployment produksi yang diverifikasi. Docker dan TLS config disediakan tetapi belum dijalankan karena runtime Docker tidak tersedia.
- Ekspor JSON dapat memuat metadata tanpa media; ZIP memerlukan media dan seluruh sidecar yang direferensikan. History/audit berisi snapshot kasus lokal yang bisa sensitif; backup dan akses folder harus dilindungi pemilik mesin. Audit ringkas tidak mencatat API key.
- Kontrak diverifikasi di Pydantic, JSON Schema dan JCS lintas JavaScript/Python, termasuk contoh paket asli. Repo modul 2/3 tidak berada di workspace; pengujian validator independen di kedua repo itu tetap bagian serah terima tim.
