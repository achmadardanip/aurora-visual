## Interpretasi evaluasi

Evaluasi fixture memuat **3 atom dari 1 event test sintetis**. Macro-F1=1.0, contradiction F1=1.0 dan false-contradiction rate=0.0 hanya membuktikan jalur perangkat lunak pada fixture kecil. CI tetap null karena hanya ada satu unit independen. Mean inference yang terukur sekitar 1.82 ms dan peak RSS proses 253,657,088 byte pada run CPU ini; bukan benchmark GPU atau kemampuan foto nyata. Tidak ada angka yang boleh dipakai sebagai hasil skripsi.

Robustness smoke menerapkan checkpoint yang dilatih pada tensor sintetis ke descriptor piksel untuk memeriksa wiring; setiap variasi diberi `feature_compatibility=fixture_override_unvalidated`. `gold_robustness_metrics=null`. Jalur manifest/checkpoint penelitian menolak ketidakcocokan fitur. Skor alignment dan penghapusan/penambahan embedding bukan bukti faithfulness kausal pada piksel.

- Tahap 1 ditingkatkan dari deteksi marker byte menjadi validasi manifest nyata: c2pa-python dipasang sebagai dependensi utama, manifest diurai dari byte asli, tanda tangan divalidasi terhadap trust store bawaan SDK (+ anchor operator), digitalSourceType algoritmik terlatih pada manifest tervalidasi dapat menaikkan label `likely_ai_generated`, dan manifest tak tervalidasi dilaporkan `present_unverified`. Round-trip nyata (tanda tangan ECDSA rantai CA+leaf openssl → verifikasi) lulus pada mesin ini.
- Adapter SynthID Detector (`aurora_visual/synthid.py`) ditambahkan untuk deteksi watermark tak terlihat: kontrak gateway ketat, kebijakan konfigurasi (enabled mewajibkan endpoint+key), opt-in per analisis dengan disclosure egress, verdikt negatif tidak dibaca sebagai bukti asal kamera, dan kegagalan provider menandai run partial. Status mock_verified karena portal resmi belum menyediakan API publik.
- Pemilihan provider ganda: Hive (deteksi AI/deepfake Tahap 1) dan DeepSeek Flash (multimodal Tahap 2–3) dapat aktif bersamaan; egress disclosure menyesuaikan (Hive hanya byte asli Tahap 1 saat keduanya dipilih). Checkbox SynthID dihapus dari layar analisis; hint "Wilayah visual" kini memakai style `.field-hint` yang benar.
- Provider DeepSeek Flash (V4.1) untuk Tahap 2–3: adapter vision + `json_object` dengan thinking mode dimatikan, validasi ulang ketat, kebijakan konfigurasi, opsi UI + disclosure egress, fallback rules, dan uji mock/pipeline lengkap (live menunggu API key).
- Model pretrained per kapabilitas: registri + CLI `aurora models` (unduh eksplisit, lisensi, sha256), integrasi Mask R-CNN sebagai proposal region opsional dengan fallback grid berperingatan, dan unduhan live 4 grup (~1,86 GB); head S/C/U tetap satu-satunya komponen trained.
- Corpus curation MAFINDO V2: puller paginasi + resume + dedup + redaksi key; **36.127 record live** diambil 14 September 2026. Corpus = kandidat caption benchmark parser + sumber teks weak-supervision; bukan dataset visual.
- LLM judge gratis (Ollama lokal): triage caption (klaim visual vs non-visual, jenis klaim) dan QC pasangan weak-supervision (parafrasa harus mempertahankan makna; perturbasi harus mengubah klaim; verdict inkonsisten ditolak). Live-verified dengan `qwen2.5:7b-instruct`.
- Optuna tuning (`aurora tune`): TPE multivariate atas learning rate/hidden/method/use_unmatched/bobot loss dengan objektif macro-F1 validasi, storage sqlite resume, best config untuk `aurora train --config`.
- Modal GPU training (`scripts/modal_train.py`, extra `modal`): image repo + torch + optuna, GPU per-run, volume artefak, jalur train dan tune; live smoke pada Tesla T4 lulus.
- Importer kapabilitas 11 sumber (5 caption → manifest `Example`, SNLI-VE dengan label weak E/C/N→S/C/U; 6 kapabilitas → manifest `CapabilityExample`); ID konten-derived, split-leakage dan path-escape ditolak; diuji dengan fixture sintetis per format rilis resmi.
- Peta jalan dataset per kapabilitas (segmentasi objek, relasi/atribut, penghitungan penuh, geolokasi, identitas orang, validasi tanggal foto, head tiga keadaan) dengan verifikasi sumber primer 13–14 September 2026 didokumentasikan di [docs/data.md](docs/data.md).
- Pengujian browser yang sebelumnya gagal karena browser pengujian belum tersedia kini lulus dengan `make browser-test`.
- `predict`/`evaluate` memeriksa encoder/preprocessing/grid terhadap checkpoint, termasuk bila dimensi tensor tetap sama. Default alignment mengikuti checkpoint, dan override eksplisit tetap didukung serta dicatat.
- Robustness memakai metode checkpoint dan menolak fitur yang tidak cocok pada jalur penelitian; pengecualian fixture smoke dinyatakan dalam output.
- Lima tes regresi ditambahkan untuk perilaku tersebut. Panduan browser, evaluasi, konfigurasi proxy lokal dan dokumen status ini dilengkapi.

## Cara menjalankan

```sh
make setup
make dev
```

Buka [UI lokal](http://127.0.0.1:5171) dan [OpenAPI](http://127.0.0.1:8101/docs). `make demo` juga menjalankan aplikasi. Pilih **Dukungan**, **Bantahan**, atau **Tak teramati**, lalu **Jalankan analisis**. Tidak membutuhkan API key/GPU atau bobot besar. Setup dependency dan pemasangan browser pertama memerlukan internet.

Pada pemeriksaan akhir, API lokal memberikan `/health` **200 ok** dan `/ready` **200 degraded**: database, worker, demo, warna lokal, OCR, **OpenCLIP** (`ViT-B-32-quickgelu/openai`, bobot terunduh), **Ollama** (`qwen2.5:7b-instruct` lokal), **Hive V3 VLM** dan **Hive V3 deteksi AI/deepfake** siap (`ok`); kapabilitas Hive V2 melaporkan status `optional` (tidak menurunkan readiness); kapabilitas baru **validasi C2PA c2pa-python** (`origin-screen-v1`) melaporkan `ok`, **torchvision-maskrcnn** melaporkan `ok` setelah bobot terunduh, **deepseek-flash** dan **synthid-detector** melaporkan `unconfigured` (tidak menurunkan readiness karena provider opt-in). Status `degraded` kini hanya berasal dari head penelitian (`AURORA_CHECKPOINT`) yang memang belum tersedia. Instansi lokal siap dipakai langsung: parser aturan/Ollama/Hive V3, backbone lokal/OpenCLIP, deteksi AI/deepfake Hive V3, serta validasi C2PA dapat dipilih/dijalankan di UI tanpa konfigurasi tambahan; deteksi watermark SynthID menunggu gateway operator.

Lingkungan aktual: macOS 27.0 arm64, Python 3.12.13, Node 26.0.0, npm 11.12.1, uv 0.12.8, PyTorch 2.14.0, Ollama 0.30.8. MPS tersedia, CUDA tidak; training/evaluasi smoke memakai CPU. Tesseract memiliki bahasa `ind` dan `eng`. Repository Git dipublikasikan pada `main` di commit `1a7b0523b53f3c581f94f246b775ea50a630d382`; hardening produksi saat ini berada di branch `production-hardening` dan belum dipush.
